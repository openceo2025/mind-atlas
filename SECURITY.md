# Security policy

## Reporting

Please do not open public issues for vulnerabilities, exposed credentials, or
reports containing personal data. Contact the project owner through the
official repository or the service contact address listed on
`https://mind-atlas.org/privacy.html`.

## Sensitive data

Never include API keys, OAuth secrets, Stripe secrets, VPS keys, database URLs,
session cookies, private notebooks, customer records, access logs, billing
records, or AI request logs in issues, pull requests, screenshots, or example
files.

## Supported surface

The public repository contains the AGPL community source and deployment
templates. The production `mind-atlas.org` service runs with private
environment files and operational data outside the repository.

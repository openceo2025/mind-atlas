# Mind Atlas trademark policy

The GNU Affero General Public License governs copyright permissions for the
Mind Atlas software. It does not grant trademark rights.

This policy covers the unregistered `Mind Atlas` word mark, the official Mind
Atlas logo and icons when used as source identifiers, `mind-atlas.org`, and
other branding that identifies an official Mind Atlas release or service.
These marks are controlled by the Mind Atlas project owner.

## Uses that do not require permission

You may:

- truthfully state that software is based on, compatible with, or derived from
  Mind Atlas;
- link to the official repository or website;
- use the name in news, commentary, reviews, tutorials, academic work, and
  comparisons;
- show unmodified screenshots for documentation, commentary, or discussion;
- describe a fork as, for example, "`Example`, a fork of Mind Atlas", provided
  the fork has its own primary name and branding.

These uses must not imply sponsorship, endorsement, certification, or official
status.

## Uses that require written permission

Written permission is required to:

- name a product, service, company, package, application, or domain `Mind
  Atlas` or a confusingly similar name;
- use the official logo or branding as the primary identity of a modified
  distribution or hosted service;
- describe a modified build as an official Mind Atlas release;
- use the marks in advertising, merchandise, or commercial sponsorship in a
  way that suggests endorsement;
- register confusingly similar trademarks, social accounts, package names, or
  domains.

## Forks and modified distributions

Forks are welcome under the software license. Publicly distributed or hosted
modified versions must:

1. use a distinct primary product name;
2. replace the official logo and source-identifying visual branding;
3. clearly state that the version is modified and is not an official Mind
   Atlas release; and
4. preserve all copyright and license notices required by the GNU AGPL.

The factual phrase "based on Mind Atlas" may be used in a secondary,
non-confusing manner.

## No effect on copyright permissions

This policy does not limit rights granted by the GNU AGPL to copy, modify, or
distribute the software. It only addresses use of source-identifying marks.

Requests for trademark permission should be directed to the owner of the
official repository at <https://github.com/openceo2025/mind-atlas>.

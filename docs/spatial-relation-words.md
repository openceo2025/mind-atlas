# 線の言葉（関係線の種類）

MindAtlas β の関係線は、名詞のラベルではなく**カードとカードの間に入る言葉**で読む。
「値上げする **だから** 解約が増える」のように、線を文として声に出して読めることを目指す。

## 仕組み

- 言葉はすべて、見えない**土台（core）**を 1 つ持つ（`spatial/src/lib/relationCatalog.ts`）。
  推論は土台だけを見るので、セットが違っても同じ土台の言葉は同じ計算に乗る。
- **表と裏**：向きのある言葉は 1 本の線に 2 つの読みがある。選んだカードから読む
  （「だから」の線は、結論のカードから見ると「なぜなら」）。矢印も読む向きに付け替える。
- **セット**は空間ごとに選ぶ（凡例・線の小窓・空間を作るとき）。セットは選べる言葉を変えるだけで、
  引いた線は消えない。今のセットに同じ土台の言葉があれば、表示はその言葉になる。
- **自分の言葉**：言葉・逆の読み（任意）・意味のひとこと・向き・色。判断モデル（Jev）は選べるが、
  土台が無いので推論には使わない。
- **Jev の判定**：線を引くと「言葉なし」で作り、裏で Jev に今の言葉から選ばせる。向きのある言葉は
  「a → b」「b → a」を別の選択肢にして向きも同時に選ぶ。人が先に選べば人が勝つ。

## 3 つのセット

| セット | 誰向け | 言葉（表 / 裏） |
|---|---|---|
| 考える（既定） | アイデア出し・メモ | つまり / だから・なぜなら / たとえば・まとめると / でも |
| 原因を探る | なぜなぜ分析・問題解決 | 結果・原因 / 強める・強められる / 弱める・弱められる / でも |
| 論理・論証 | 論理を学んだ人 | 演繹：十分条件・必要条件 / 必要十分条件 / 矛盾 / 両立しない、論証：根拠・主張 / 反論、集合：属する（∈）/ 含まれる（⊆）/ 構成要素 |

## 推論（`spatial/src/lib/inference.ts`）

演繹（「必ず」）の線だけで計算するもの：

- 推移：A⇒B, B⇒C ⊢ A⇒C。⇒ が輪になれば同値。
- 対偶：A⇒B, A と A' が矛盾, B と B' が矛盾 ⊢ B'⇒A'。
- 両立しないことの伝播：A⇒X, X と Y は両立しない ⊢ A と Y も両立しない。
- 自己矛盾：A から、両立しない 2 つが両方言えるなら A は成り立たない。
- 集合：⊆ は推移、a∈A かつ A⊆B ⊢ a∈B（∈ は推移しない）。構成要素は推移するが、性質は受け継がない。

論証（「たいてい」）の線は、「だから」「根拠」をつないだ先を「たぶん」として提案し、
「でも」「反論」とぶつかる組を注意として出すだけ。対偶や伝播には使わない。

因果の線からは、根本原因（それ以上さかのぼれないカード）と、輪を探す。輪の「弱める」が
偶数本なら強め合う輪（悪循環・好循環）、奇数本なら歯止め。

結果は「関係の発見」の小窓（凡例の「推論を見る」からも開く）に、根拠になった線と一緒に出る。
「線にする」で実際の線にできる。

## 移行

以前の `supports` は「だから」、`contradicts` は「でも」に読み替える（読み込み時）。
`related` は「言葉なし」の線として残る。`source`・`derived`・`contains` はアプリが引く線で、言葉ではない。

検査：`npm run verify:spatial-relations`
